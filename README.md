A tiny program that writes one funny, human single-sentence apology from an AI assistant to the person it works for into `/output/entry.txt` — for the The One-Sentence Apology Your Agent Owes You bounty on make.fun.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
